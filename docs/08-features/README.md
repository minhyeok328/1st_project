# 기능 명세

| 기능 | 선행 조건·입력 | 동작·출력 | 경계 |
| --- | --- | --- | --- |
| 차량 조회 | 모델명·DB | 부분일치 결과 | DB 오류도 빈 결과가 될 수 있음 |
| 등급·연도 필터 | 체크박스 활성화 | 일치 행 표시 | 빈 결과면 중단 |
| 가격 선택 | 제원 선택 | 연결 행 또는 후보 선택 | 연결 없음이면 수동 선택 |
| 주행 조건 | 패턴·월 거리 | 효율·연간 거리 | 0·비수치 효율 방어 부족 |
| 부품 조정 | 배기량·기준표 | 단가 편집·예상 개월 | 정비 이력 반영 없음 |
| 유가 | 결과 버튼 | 조회 또는 대체 단가 | 최신 값과 대체값 구분 불충분 |
| 결과 | 선택 완료 | 항목별 월·연 비용 | 저장·다운로드 없음 |

## 변경 시 연결 지점

- CSV 열 변경: `package_loader.py` 스키마와 `main.py` 인덱스를 확인합니다.
- 연료명 추가: 검색 매핑·대체 단가·표시 단위·전기차 제외 조건을 함께 확인합니다.
- 정비 기준 변경: DB와 캐시, 0·NULL 교체주기를 확인합니다.
- 비용 추가: 연간 합계·월 환산·내역 표·설명 문구를 함께 반영합니다.
