# 데이터 흐름

## CSV 적재

`csv_import()`가 UTF-8 CSV를 헤더 처리 없이 튜플 목록으로 읽습니다. `export_table()`이 대상 테이블을 재생성하고 빈 문자열과 `None`·`Null`·`NULL` 문자열을 SQL NULL로 바꾸어 INSERT를 만듭니다. 가격을 먼저 적재하고 가격 모델명을 참조하는 연비 데이터를 적재합니다.

SQL 값은 문자열 조합으로 생성됩니다. 열 수뿐 아니라 작은따옴표·중복 모델명·외래키 대상도 확인해야 합니다. `csv_merge()`는 첫 필드가 중복되면 첫 번째 파일의 행을 유지하며 열별 값 병합은 하지 않습니다.

## 조회와 선택

`db_search('car_oil', model_name)` → 등급·연도 필터 → 세부 모델 선택 → `in_oil` 저장 순서입니다. 마지막 `price_model` 필드는 표에서 제외합니다. 연결이 있으면 가격 테이블을 직접 조회하고 없으면 사용자가 가격 후보를 선택합니다.

튜플 인덱스로 값을 읽으므로 [DB 열 순서](../05-database/schema-and-erd.md)를 바꾸면 화면과 계산도 확인해야 합니다. 선택 행을 다시 찾는 루프는 원본 검색 결과를 순회하므로 필터 결과와의 일치 여부도 검증합니다.

## 결과 생성

월간 거리 → 연간 거리 → 주행 패턴별 효율 → 배기량별 부품 단가 → 전기차 제외 항목 → 사용자 편집 금액 → 유종 단가 → 연료비·세금·정비비 → 월·연 합계 순서입니다.

유가 조회는 결과 버튼을 누를 때 수행합니다. 차량 가격은 요약 표시용이며 합산식에 들어가지 않습니다. 결과 저장·내보내기나 자동 데이터 갱신 작업은 없습니다.
