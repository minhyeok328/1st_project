# 화면 구현

## 진입점과 상태

`main.py`에서 Streamlit 위젯과 인라인 CSS를 구성합니다. 넓은 레이아웃과 최대 80% 콘텐츠 너비를 사용합니다. 별도 프런트엔드 라우터는 없습니다.

| 세션 키 | 의미 |
| --- | --- |
| `model_name`, `use_grade`, `in_grade`, `use_year`, `in_year` | 검색 입력·필터 |
| `open_result` | 최초 검색 이후 상세 영역 표시 |
| `in_oil` | 선택 차량 DB 튜플 |
| `in_price`, `in_price_selected` | 가격 정보와 위젯 값 |

검색 전·결과 없음·모델 미선택 상태에서는 `st.stop()`으로 뒤쪽 화면을 중단합니다. `open_result`는 한번 참이 되면 유지되므로 이후 위젯 변경으로 재실행될 때도 검색 로직을 통과합니다.

## 화면 계약

- 모델명 기본값은 아반떼, 주행거리 기본값은 월 1,500km입니다.
- 패턴은 복합·도심·고속도로 중 하나입니다.
- `st.data_editor`에서 부품 가격만 수정할 수 있고 이름·주기·예상 시기는 잠깁니다.
- 결과는 정수 금액으로 표시합니다. 차량 사진은 DB의 외부 URL을 사용합니다.
- 월 거리와 편집 단가의 음수 입력 방지가 충분하지 않습니다.
