# 프로젝트 개요

## 목적과 범위

TCO Insight는 차량의 반복 운영비를 같은 주행 조건으로 계산하는 학습용 웹 애플리케이션입니다. 모델명으로 차량을 고르고 주행 패턴·주행거리·부품 단가를 입력하면 연료비, 자동차세, 정비비를 합산합니다.

차량 구매비, 보험료, 할부 이자, 주차비, 통행료, 감가상각은 계산에서 제외합니다. 가격 범위는 차량 정보로 표시할 뿐 합계에 더하지 않습니다. 사용자가 조건을 바꾸어 결과를 확인하는 방식이며 여러 차량의 결과를 동시에 비교·저장하는 기능은 없습니다.

## 데이터 기준

| 파일 | 로컬 파일 확인 결과 | 용도 |
| --- | --- | --- |
| `data/vehicles/car_oil.csv` | 헤더 없이 506행, 12필드 | 모델·연료·효율·배기량·연식·가격 연결 |
| `data/vehicles/car_price.csv` | 헤더 없이 268행, 4필드 | 모델명·최저가·최고가·이미지 주소 |
| `database/init/DBsetup.sql` | 기준 부품 10개 INSERT | 교체 거리와 A/B/C 단가 |

수치는 저장소 파일 기준이며 실행 중인 DB 행 수나 최신 차량 정보 범위를 뜻하지 않습니다. 수집 시각·갱신 주기와 부품별 단가 산정 근거는 별도로 관리되지 않습니다.

## 구현과 수집 모듈

메인 화면은 DB에 적재한 차량 데이터를 읽습니다. `API_Side/CarOil.py`, `CarPrice.py`는 별도 수집 모듈이며 메인 검색에서 직접 호출되지 않습니다. 결과 계산 시 `OilPrice.getdata()`로 유가를 조회합니다. 실패 시 대체 단가가 사용되므로 화면의 실시간 문구만으로 데이터 신선도를 판단할 수 없습니다.
