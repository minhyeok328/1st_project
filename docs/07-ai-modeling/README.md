# 계산 모델

학습한 AI 모델은 없습니다. `main.py`의 결정식으로 운영비를 계산합니다. 아래 수치는 구현 설명이며 현재 세법·시장 단가를 검증한 안내가 아닙니다.

## 산식

월간 거리 `m`, 효율 `e`, 연료 단가 `p`, 부품 교체 거리 `c_i`, 편집 금액 `v_i`를 사용합니다.

```text
연간 거리 d = 12 × m
연간 연료비 = d / e × p
연간 정비비 = Σ(d / c_i × v_i)
연간 운영비 = 연료비 + 자동차세 + 정비비
월간 운영비 = 연간 운영비 / 12
교체 예상 개월 = int(c_i / m), m <= 0이면 0
```

정비비는 교체 횟수를 정수로 세지 않고 거리에 비례해 배분합니다. 현재 누적거리·부품 교체 이력·차령은 반영하지 않습니다.

## 차량 구간

| 조건 | 부품 단가 |
| --- | --- |
| 배기량 1,000cc 이하 | Tier A |
| 1,000cc 초과~2,000cc 이하 | Tier B |
| 2,000cc 초과 | Tier C |
| 배기량 없음·숫자 문자열 아님 | 0cc로 처리 |

Tier는 브랜드·수입 여부가 아닌 배기량만으로 정합니다. 연료가 `전기`이면 엔진오일·점화플러그·타이밍벨트/체인·미션오일을 제외합니다.

## 연료 단가

가솔린→휘발유, 디젤→경유, LPG→자동차용부탄가스, 전기+휘발유·휘발유 하이브리드→휘발유로 매핑합니다. 다른 연료는 휘발유 검색이 기본입니다. 전기는 조회 없이 347원/kWh를 사용합니다.

조회가 0 이하이면 원래 `fuel_type` 문자열에 따라 휘발유 포함 1,650원/L, 경유 포함 1,500원/L, 전기 포함 347원/kWh, 나머지 1,000원을 적용합니다. 따라서 `가솔린`·`디젤` 표기에서는 1,000원 대체값이 적용될 수 있습니다. PHEV의 전기 충전비를 따로 분리하지 않습니다.

## 자동차세와 해석 범위

전기는 연간 130,000원입니다. 나머지는 1,000cc 이하 80원/cc, 1,600cc 이하 140원/cc, 초과 200원/cc를 선택해 `int(cc × 단가 × 1.3)`으로 계산합니다. 차령 할인·차종·용도별 예외는 구현하지 않습니다.

부품 단가의 평균·중앙값 산정 자료와 세율 최신성 근거는 별도로 포함되지 않습니다. 차량 가격·보험료·금융비·감가상각은 합계에 들어가지 않습니다.
